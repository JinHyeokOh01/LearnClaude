## 이게 왜 필요한가

폴더마다 작업 방식이 다르다면, 그 규칙을 매번 말하는 건 번거롭다.
지침 파일을 폴더에 두면 그 폴더에서 일할 때 규칙이 자동으로 적용된다.
"이 프로젝트에서는 이렇게"를 한 번 적어두면 계속 유효하다.
