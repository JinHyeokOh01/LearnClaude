## 이게 왜 필요한가

파일 작업·커스텀 명령·지침을 엮으면 터미널이 나만의 자동화 도구가 된다.
매주 반복하던 절차를 한 번 설계해두면, 다음엔 명령 한 줄로 끝난다.
이 트랙의 마지막은 개별 기능을 넘어 "내 반복 업무를 시스템화"하는 것이다.
