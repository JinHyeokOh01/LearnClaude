## 이게 왜 필요한가

설치라고 하면 어렵게 느껴지지만, 안내를 따라가면 몇 분이면 된다.
설치 후 폴더 안에서 실행하면 그 폴더의 파일을 바로 다룰 수 있다.
첫 대화로 "이 폴더 살펴봐"부터 시작하면 감이 잡힌다.
