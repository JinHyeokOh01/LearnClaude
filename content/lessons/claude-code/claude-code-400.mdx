## 이게 왜 필요한가

파일 하나하나 열어 같은 수정을 반복하는 건 시간 낭비이자 실수의 원인이다.
"모든 파일에 이걸 적용해줘" 한 번이면 수십 개가 일관되게 처리된다.
이름 변경, 머리말 추가, 형식 통일 같은 반복 작업에 강력하다.
