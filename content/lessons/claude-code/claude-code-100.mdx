## 이게 왜 필요한가

"Claude Code = 코딩 도구"라고 생각하면 절반만 아는 것이다.
본질은 "터미널에서 내 폴더의 파일을 다루고 작업을 맡기는 도구"다.
문서 일괄 변환, 파일 정리, 반복 작업 자동화 등 비개발 업무에도 쓸 수 있다.
