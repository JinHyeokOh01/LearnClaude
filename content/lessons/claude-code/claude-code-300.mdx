## 이게 왜 필요한가

Claude Code는 폴더의 파일을 직접 읽고 고칠 수 있다.
"이 파일 이렇게 정리해줘"라고 하면 열어보고 수정안을 만든다.
문서 정리·형식 통일 같은 작업을 터미널에서 바로 처리할 수 있다.
