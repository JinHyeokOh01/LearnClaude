## 이게 왜 필요한가

긴 지시를 매번 입력하는 대신, 짧은 명령어 하나로 등록해두면 편하다.
자주 반복하는 작업일수록 커스텀 명령의 가치가 커진다.
"내 자주 쓰는 작업"을 명령으로 만들면 터미널이 나만의 도구가 된다.
