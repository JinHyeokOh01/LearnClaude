## 이게 왜 필요한가

파일을 직접 바꾸는 만큼, 되돌릴 방법을 미리 마련해두는 게 중요하다.
"바꾸기 전 백업"을 규칙으로 두면 실수해도 원래대로 돌릴 수 있다.
안심하고 더 과감하게 작업을 맡길 수 있게 된다.
