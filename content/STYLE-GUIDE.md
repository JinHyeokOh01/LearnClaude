# 콘텐츠 스타일 가이드 (T-70)

> 이 문서는 빌드에 포함되지 않는 저자용 가이드입니다.

## 필수 규칙 (requirements §4.2)

- **CR-1** 첫 문단은 "이걸 알면 뭐가 달라지는지"를 실무 상황으로 제시
- **CR-2** 공식 문서(docs.claude.com / support.claude.com / claude.com) 출처 최소 1개
- **CR-3** `verifiedAt`에 작성·검증 시점 기록. 90일 초과 시 재검증
- **CR-4** 유료 플랜·데스크톱·플랫폼 요구 시 `requires`로 명시
- **CR-5** 실습은 사용자의 실제 업무 파일 없이도 수행 가능 (샘플/가상 상황)
- **CR-6** 레벨 — 1: 채팅 UI 완결 / 2: 파일·도구 연결 / 3: 설정·구조 설계

## 형식

- 제목 40자 이내, 요약 80자 이내
- 본문은 읽는 시간 3분(한국어 약 900자) 내외
- 미션: 목표 1문장 / 복붙 프롬프트 / 성공 기준 1문장
- `order`는 100 단위 간격 (NFR-16), `id`는 발행 후 변경 금지 (NFR-17)
- 톤: 존댓말, 실무자 대상, 과장 없이 담백하게

## ⚠ 사실검증 상태

현재 작성된 강의 본문은 **AI가 쓴 1차 초안**입니다.
Claude 기능은 자주 바뀌므로, 발행 전 반드시:
1. 각 레슨의 기능 설명을 공식 문서와 대조
2. `sources`의 URL을 실제 문서 링크로 교체 (현재는 플레이스홀더 포함)
3. 실습 미션 프롬프트를 실제 Claude에서 실행해 성공 기준 확인
4. 확인 완료 후 `verifiedAt`을 검증일로 갱신

이 검증은 tasks.md T-78에 해당합니다.
